B2B Ordering & Diagnostics AgentFlagship

An AI agent that turns a contractor's or property manager's request into a correct, compatible, policy-approved order of parts, tools and installer services, and diagnoses faults from photos and telemetry.

The Problem

Business buyers lose time and money to one question: which part fits which asset. Crews ask by description ("the fine blade for the 18V saw"), the same appliance model has revisions that take different parts, approvals live in email, and gas or sealed-system repairs legally need a certified installer. A wrong part means a return trip, or a safety hazard.

What I Built

  • The PRD, agent architecture requirements and product policy for an agent that identifies the asset, verifies fit, checks company spend policy, then buys or books after approval.
  • Layered guardrails: deterministic fitment, spend and safety checks the model can't override; a quarantined reading agent with no tools for untrusted content like reseller listings and photos; and human confirmation on every order, with approver sign-off on exceptions.
  • The eval strategy end to end: a flow-based data plan of 600+ samples across 40+ user flows, a 43-eval catalog of code checks and 25 LLM judges, each calibrated against hand-labeled samples, plus labeling guides.
  • A 500-case prompt-injection stress set that runs on every model in use, including backup models.

PM Instinct Behind It

  • The model proposes, code verifies. A source of truth already exists for fit, policy and price, and a 99.5% fitment-precision bar can't rest on the model never making a mistake.
  • Verified correct, not "marked done." The north star is a weekly human audit of 400 orders: right SKU, confirmed fit, within policy, not returned for fit in 30 days.
  • Autonomy is earned. v0 recommends, v1 buys after one-click approval, v2 auto-buys inside policy.
  • Limit what the reading agent can do instead of trusting filters. Outside content can inform a recommendation but can never trigger an action.

Targets and Open Problem

Targets: 15% of B2B direct revenue routed through the agent (the main product Goal), verified-correct order rate ≥97%, order approval time 2.5 days → <4 hours, fit-related returns 3.1% → ≤2%. Open problem: the diagnosis path is modeled at about $1.06 per completed order against a $0.60 target, and caching alone can't close the gap.

Self-Evolving Agentic AI Platform

A human-in-the-loop platform that lets production AI agents keep improving from videos of experts correcting agent outputs.

+22%accuracy on 2 production agentic systems
3customers onboarded in 2 months
Hide detailsView details

The Problem

Agents in production lose accuracy as the data they see drifts or as they hit edge cases and unique scenarios, and expert corrections usually stay with the expert instead of reaching the agent.

What I Built

  • Led product strategy for an automated human-in-the-loop learning platform that turns experts' correction workflows, captured on video, into a knowledge base for agent improvement.
  • Defined the feedback-loop architecture, the evaluation framework and reliability guardrails with engineering.

PM Instinct Behind It

An agent that learns from new data can also learn the wrong thing. Pairing the feedback loop with an evaluation framework and guardrails keeps trust calibrated under drift and non-deterministic outputs, so each improvement is measured instead of assumed.
